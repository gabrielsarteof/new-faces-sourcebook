# Clãs — Naruto

Cada clã define multiplicadores de PM, habilidades inatas (obrigatórias) e habilidades raras (compráveis com XP).

## Como Clãs Funcionam
- Todo clã tem **1+ habilidades obrigatórias** — adquiridas automaticamente ao selecionar o clã
- **Habilidades raras** são compradas com XP durante a progressão
- Alguns clãs têm **linhagens associadas** (ver [Linhagens](../lineages/overview.md))
- O custo de XP de clã é geralmente 0 — exceções de tier alto podem ter custo de núcleo
